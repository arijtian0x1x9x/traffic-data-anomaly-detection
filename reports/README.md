# Results

Read [the reference report](reference/RESULTS.md) for the supplied experiment's findings, or run
`uv run traffic-study all` to generate a new report at `reports/RESULTS.md`.

`reference/` contains shareable numerical results and figures. A new run writes metrics to `results/`
and charts to `figures/`. Automated notebook execution writes to `executed_notebooks/`. These generated
outputs are excluded from Git so they can be reviewed separately before sharing.
